# 2026 爱知·名古屋亚运会男篮数据分析

基于官方实时成绩系统公开数据，对中国、日本、韩国、伊朗四支男篮各 6 场比赛进行整理，并重点分析两场半决赛、三四名决赛和决赛。

项目包含官方原始 JSON、可复现的数据处理代码、逐场与逐事件 CSV、Excel 报告，以及一份面向 B 站的视频脚本。

## 主要结论

- 韩国 6 战全胜，整体进攻效率、阵地战效率和三分命中率均为四队最高。
- 中国场均 90.5 分，但数据受到前三场大胜影响。前四场估算进攻效率为 126.9、防守效率为 83.0；最后两场分别变为 100.9 和 120.8。
- 中国最后两场两分球命中率从前四场的 63.9% 降到 42.0%，对手三分球合计 27/63。
- 中国对日本的半决赛主要是防守失效；对伊朗的三四名决赛则是阵地进攻、三分防守和防守篮板共同出现问题。
- 中国拥有较强的传统篮球基础，但现代篮球所要求的空间、出手价值、连续决策和攻防闭环仍不稳定。

## 快速复现

仅需 Python 3.10+，不依赖第三方包。

```bash
python3 scripts/download_official_data.py
python3 scripts/build_dataset.py
python3 scripts/export_csv.py
```

如果只想下载涉及四支目标球队的 19 场比赛：

```bash
python3 scripts/download_official_data.py --target-only
```

## 计算口径

- 总回合估算：`FGA - ORB + TO + 0.44 × FTA`
- 总进攻效率：`球队得分 ÷ 估算回合 × 100`
- 三分得分效率：`3 × 3PM ÷ 3PA`
- 估算快攻回合：防守篮板或对手失误后 7 秒内出现本队首次出手、罚球或失误；官方 `P2F/P3F` 标记强制纳入。
- 估算阵地战：总得分和总回合分别减去估算快攻得分与快攻回合。

快攻与阵地战是基于逐事件数据的近似估算，不等同于录像标注或商业数据服务定义。详细说明见 [`docs/methodology.md`](docs/methodology.md)。

## 已知数据问题

- 中日半决赛官网顶层 `Result` 字段显示 97–78，但球队分项、逐事件终场值和日本篮协记录均为 97–77。本项目采用 97–77，并保留异常备注。
- 官方 `P2F/P3F` 快攻标签并不覆盖所有快攻投失、罚球与失误，因此另行提供 7 秒规则估算值。
- 本项目没有观看比赛录像，无法判断具体防守策略、掩护方式或每次轮转责任。
